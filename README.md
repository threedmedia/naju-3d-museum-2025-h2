## 📖 소개
이 프로젝트는 '2025 하반기 자랑스러운 나주알기 : 내가 만드는 3D 역사박물관'에 참여한 학생들의 프로젝트의 포트폴리오를 엿볼 수 있는 웹사이트이며, 학생들이 활동 결과물과 활동 사진 등을 볼 수 있게 진행된 웹사이트이다.
